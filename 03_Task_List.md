## 3. Quy ước trạng thái

| Trạng thái     | Ý nghĩa                                        |
| -------------- | ---------------------------------------------- |
| Hoàn thành     | Chức năng đã được triển khai trong source code |
| Đang thực hiện | Đang trong quá trình hoàn thiện                |
| Chưa thực hiện | Chưa triển khai hoặc chưa xác nhận hoàn thành  |
| Đề xuất        | Chức năng dự kiến phát triển trong tương lai   |

**Lưu ý:** Trạng thái Hoàn thành phản ánh chức năng đã xuất hiện trong source code được kiểm tra, không đồng nghĩa với việc chức năng đã vượt qua kiểm thử.

## 5. Công việc tiếp theo

1. Thực thi 30 Test Cases đã xây dựng.
2. Ghi nhận và sửa các lỗi phát sinh.
3. Kiểm tra bảo mật Gemini API Key.
4. Kiểm tra khả năng xử lý các video có độ dài khác nhau.
5. Hoàn thiện tài liệu dự án.
6. Chuẩn bị slide thuyết trình.
7. Kiểm tra tổng thể trước khi bàn giao.
